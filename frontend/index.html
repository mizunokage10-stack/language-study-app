以下をコピーして、ChatGPTに貼り付け後、末尾に文章を追加してください。

以下の文章を、言語学習アプリの読解パートに登録できる教材JSONに変換してください。

目的は、文章をただ読むだけではなく、以下の6ステップで学習できるようにすることです。
1. 初読  2. 確認設問  3. 精読・語彙整理  4. 再読  5. 音読・シャドーイング  6. 1文アウトプット

以下の条件に従って、必ずJSONのみを出力してください。説明文、前置き、Markdownのコードブロックは不要です。

【重要】出力は、JSON.parseでそのまま読み込める厳密なJSONだけにしてください。
JSONのキー名と文字列は、必ず半角ダブルクォート " で囲んでください。
スマートクォート “ ” や ‘ ’ は絶対に使わないでください。
Markdownのコードブロック、説明文、前置き、末尾コメントは不要です。

ただし、explanation・explanationJa・note・instruction などの文字列の中で英語フレーズを引用する場合は、半角ダブルクォート " ではなく、日本語の鍵括弧 「 」 を使ってください。

例：
正: "explanation": "本文の冒頭で 「Outdoor drinking should be prohibited」 と述べており..."
誤: "explanation": "本文の冒頭で "Outdoor drinking should be prohibited" と述べており..."
誤: “explanation”: “本文の冒頭で 「Outdoor drinking should be prohibited」 と述べており...”
